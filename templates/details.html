Machine Learning Project Details

1. Custom Exception Handling & Logging

As a foundational step, we set up robust monitoring and error tracking:

  • Logger: Implemented a custom logging mechanism (src.logger) to record all the execution steps, errors, and system events into log files for easy debugging.
  • Exception Handling: Created a custom exception class (src.exception.CustomException) that captures detailed error messages, including the exact script name and line number where the issue occurred, making it significantly easier to trace bugs.

2. Data Source

The dataset used for this project is stud.csv, which contains details regarding student performance. It was ingested locally from the notebook data directory.

3. Handling Missing (NaN) Values

We addressed missing values using the SimpleImputer class from sklearn.impute. Specifically:

  • Numerical Features: Imputed using the median strategy.
  • Categorical Features: Imputed using the most frequent (mode) strategy.

4. Data Transformation Pipeline

The data was processed using a ColumnTransformer to apply specialized pipelines to different types of data:

  • Numerical Columns (writing_score, reading_score): After imputation, the data was standardized using StandardScaler.
  • Categorical Columns (gender, race_ethnicity, parental_level_of_education, lunch, test_preparation_course): After imputation, the features were encoded using OneHotEncoder and subsequently scaled using StandardScaler(with_mean=False).
  • The target variable for prediction is math_score.

5. Models Trained

We trained and evaluated a variety of robust machine learning regressors to find the best-performing model:

  • Random Forest Regressor
  • Decision Tree Regressor
  • Gradient Boosting Regressor
  • Linear Regression
  • XGBoost Regressor (XGBRegressor)
  • CatBoost Regressor
  • AdaBoost Regressor

7. Frontend & Deployment

At the end of the project, we built an interactive web interface using Flask. This frontend allows users to input specific student demographics and scores, and receive a predicted math score via our trained data pipeline and best model. The final application has been successfully deployed on Render, making the model easily accessible over the web.
